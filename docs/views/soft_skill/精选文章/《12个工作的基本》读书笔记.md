# 《12个工作的基本》读书笔记

    引言：职业生涯是偶发性学习的积累；
    
    
       引导职业生涯走向成功的关键在于有计划地开发自己的能力。
    
    
       12个能力分为“对己”“对人”“对课题”三种。
    
    
      
    
    
    
    1、反应力 表情、点头 信息收集能力、正视眼睛、提问 
    
    
    ——结合传统的相面术和微表情解读相关知识背景，眼神闪躲的沟通多少有点问题。在可以面对面沟通的谈话场域，正视眼睛可以相对减少信息传递误差，准确表达意思。
    
    
      
    
    
    
    注：全文破折号后均为笔者的自我解读，仅供参考。
    
    
      
    
    
    
    2、亲和力 日本首相田中角荣 洛克希德事件 心理学家彼得·沙洛维将情商的相应部分分成五个领域来加以说明。
    
    
      1）认识自身的情绪。
    
    
      2）控制情绪。
    
    
      3）自我激励。
    
    
      4）认知他人的情绪。
    
    
      5）妥善处理人际关系。 不能省略寒暄。 
    
    
    ——早上好、午安、晚上好、明天见，从简单寒暄中建立的人际关系之始。
    
    
      此处可以部分适用儿童心理学，参照抖音各类视频里对古早综艺《爸爸去哪儿》的分析，其中“情绪韧性”这个词语可以学习和理解。
    
    
      
    
    
    
    3、乐观力 汉斯·塞利认为压力可分为两种，一种是成长、发育所必需的积极压力（eustress），另一种是不良压力（distress）。 
    
    
    直面压力根源：人际关系 
    
    
    分析压力根源：失败学，转成信息源 
    
    
    倾诉压力产生原因：朋友 
    
    
    保持乐观：以积极思考为目标、锻炼努力就能成功的思维模式、战略性思维、高忍耐力 
    
    
    ——有个词语“乐观的悲观主义者”，可理解为此处面对良性压力后的对抗压力的操作。但是对“高忍耐力”相关表达不予认可，可能我的年纪还没有到，我自己没有高忍耐力，也不赞成培养高忍耐力。该拒绝时拒绝，该反对时反对，当断不断反受其乱，该出手时还是要出手的。
    
    
      
    
    
    
    4、目标发现力 不做待命族，自立、自我负责 梦想、贪欲 
    
    
    问题发现技能：碎片化日程安排，30分钟一目标；成功印象；上司希望你成为独立型人才。
    
    
    ——看要不要摆烂了。如果职场摆烂的话，可以只对分配过来的任务有回应，可以不主动和学会拒绝。只做份内的事情是本分，帮了别人是情分。
    
    
      另外，从日常任务分解角度，建立自己的工作日程管理是很重要的；
    
    
      从管理岗角度来说，要建立团队工作日程管理（如共享电子日历）。进而是基于向上汇报思维的工作成果梳理，此时就有问题发现——问题解决。
    
    
      不仅仅是提出问题，而是给到解决方法，甚至是给到解决方案ABC（*小技巧：明知A方案最好，也要同步提交BC方案备选，这样才能解释说明为什么A方案最好）。
    
    
      
    
    
    
    5、持续学习力 柏拉图：言论力、雄辩术； 
    
    
    作者本身看书计划：经济类一年150本书、两天一本 
    
    
    学习习惯：精力集中、确定近期目标（备忘录记录进度）、记住就立刻说出来固化、习惯化
    
    
    ——我自己的年度读书计划是每年读完30-50本，但是实际上每年都有很多读了一半放弃读的，确实需要进行进度管理，提高完读率。
    
    
      
    
    
    
    6、语境理解力 感情控制力，逻辑思考力，表达能力 
    
    
    想象发言背景、整理论点的习惯
    
    
    ——反复告诫自己：事缓则圆=心急吃不了热豆腐。信息传递有很多误差、误解，不要焦躁，理性分析反馈表达。
    
    
      
    
    
    
    7、专业构筑力 已经积累大量经验的领域、较短时间达到一定水平、职务适应性 
    
    
    兼顾理论与实践、专家关系网 
    
    
    作为专家：不知者为罪
    
    
    ——任何一行从事了3个月，就应当构建行业基础认知；从事3年以上，就应当成为某种程度上的专家。需要持续关注该行业领域新情况，不断学习该行业领域的知识、政策、事件，以完善认知圈。职场人，不知=有罪。
    
    
      
    
    
    
    8、人脉开拓力 演讲——寻找长谈机会 
    
    
    初次见面铺垫下次再见面的理由 
    
    
    介绍给第三方是加深关系的技巧 怀着无私奉献的心态、锻炼自己的信息提供力、不要吝啬交际费和饮食费、个人主页上自我介绍、停止加班空出时间（效率）学习或者会客 
    
    
      
    
    
    
    9、委任力 工作委派给后辈做，应该尽量向对方表示感谢和赞赏；
    
    
    如果有需要改善的地方，再进行耐心细致的说明；说明意义 
    
    
      
    
    
    
    10、商谈力 
    
    
    分为三步：1）与对方建立彼此信赖的人际关系，并以此为基础；
    
    
         2）充分认同对方的价值观和特性（有相同目标）；
    
    
         3）提供专业的建议（基于专业知识作详细说明），让对方作出决定。 
    
    
    对下属：以成为职业顾问型上司为目标，自身需具备“专业知识”和“咨询技能”
    
    
      
    
    
    
      
    
    
    
    11、传授力 
    
    
    尽量跟受教方形成平等的伙伴关系 
    
    
    建立相互理解、彼此融洽的“和谐”关系 
    
    
    毫无保留是大忌 
    
    
    聆听与提问、夸奖（具体、当众）与责备（一对一，针对行为） 
    
    
    ——切记交浅言深、好为人师。
    
    
      
    
    
    
    12、协调力 
    
    
    专业知识、人脉、把握对方需求
    
    
    本质开朗、勤勉、为人诚实
    
    
    针对信息收集的日常活动、设定目标、促进达成共识
    
    
    适当建议。
    
    
    ——根据不同方向的需求点，平衡适当性。

    3、埃德加·沙因：自我概念是通过反复自问，自己的强项和弱点有哪些？自己的目标是什么？自己的价值观是怎样的？
    
    
    ——自己的强项和弱点：强项：民商事诉讼和法务合规、日语能力；不畏惧冲突，敢于表达诉求。弱点：没有情绪韧性，没有忍耐力。
    
    
    目标：坚守底线，不做dirty work。
    
    
    自己的价值观：社会主义核心价值观，富强、民主、文明、和谐,自由、平等、公正、法治,爱国、敬业、诚信、友善。
