工作效率-高效工作

  


工作方法是可以通过实践而提高的。只要你转变了思路并将方法落于实践，就能够提高工作效率。

“高效工作”通过三个步骤，系统地帮助职场从提高工作效率。

第一步：用“以终为始”的思维方式，确认自己做的是正确的事，并通过二八法则筛选待办事项，将精力集中在最重要的事上。

第二步：通过借助外部力量和快速迭代的工作方法，正确地做事。

第三步：在事情完成后，通过复盘总结经验。

工作效率-时间管理

  


时间是世界最公平的资源，它给每个人都是一天24小时。但不同人的时间、同一个人的不同时间，其实都不一样。

你选择在什么样的时间、什么样的状态、做什么样的事情，甚至对时间尊重到什么样的程度，都导致了不同的产出。

时间管理本质上是人生管理。你把时间花到什么地方、怎么花，决定了你会成为什么样的人。

用四个步骤系统地管理自己的时间，掌握自己的人生：

第一步：破除时间管理的误区，重新了解时间。

第二步：了解不同的时间观，形成幸福感更强的平衡时间观。

第三步：诊断自身时间管理存在的问题，有针对性地进行调整。

第四步：打造专属自己的时间管理系统，利用外部工具事半功倍。
