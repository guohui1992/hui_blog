# 虚拟机相关

拖拽功能始终异常，可通过共享文件夹实现文件互传

## 1. 设置共享文件夹

关闭虚拟机，进入 设置 → 选项 → 共享文件夹。
选择 "总是启用"，点击 "添加"，选择宿主机上的一个文件夹作为共享目录。

## 2. 安装和挂载共享文件夹

### 2.1 创建挂载点

若未创建挂载点，先创建再挂载：
```bash
sudo mkdir -p /mnt/shared
```

### 2.2 安装 open-vm-tools-fuse 组件

vmhgfs-fuse 包含在 open-vm-tools-fuse 包中，在 Ubuntu 终端执行以下命令安装：

```bash
sudo apt update
sudo apt install open-vm-tools-fuse
```

### 2.3 重新挂载共享文件夹

安装完成后，使用 vmhgfs-fuse 命令重新挂载：

```bash
# 若已创建/mnt/shared目录，直接执行挂载
sudo vmhgfs-fuse .host:/ /mnt/shared -o allow_other

# 若未创建挂载点，先创建再挂载
sudo mkdir -p /mnt/shared
sudo vmhgfs-fuse .host:/ /mnt/shared -o allow_other
```

`-o allow_other` 参数允许非 root 用户访问共享文件夹，避免权限问题。

### 2.4 验证挂载是否成功

挂载后，执行以下命令查看是否成功：

```bash
ls /mnt/shared
```

若能看到宿主机中设置的共享文件夹内容，说明挂载成功。

## 3. 设置开机自动挂载（可选）

为避免每次重启后手动挂载，可配置 /etc/fstab 实现自动挂载：

编辑 fstab 文件：
```bash
sudo nano /etc/fstab
```

在文件末尾添加一行：
```plaintext
.host:/ /mnt/shared fuse.vmhgfs-fuse allow_other 0 0
```

按 Ctrl+O 保存，Ctrl+X 退出编辑器，重启后会自动挂载。
